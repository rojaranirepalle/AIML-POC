# Wine Quality AI Dashboard

Machine Learning dashboard built with Streamlit.

## Features

- Data Analysis
- Multiple Regression Models
- Automatic Best Model Selection
- Model Persistence
- Explainability
- Prediction History
- Plotly Analytics
- CSV Export

## Models

- Linear Regression
- Ridge Regression
- Lasso Regression
- ElasticNet

## Run

```bash
streamlit run app.py
```
